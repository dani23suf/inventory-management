# Inventory Management

Simple Inventory Management System menggunakan Laravel sebagai backend API dan Vue 3 sebagai frontend.

## Tech Stack

- Laravel
- PHP
- MySQL
- Vue 3
- Vite
- Axios
- Vue Router

---

## Requirements

Pastikan sudah terinstall:

- PHP >= 8.2
- Composer
- Node.js >= 18
- NPM
- MySQL
- Laragon (optional)

---

# Installation
 1. Clone Repository

```bash
git clone <repository-url>
cd inventory-management

## 2. Install Laravel

composer install

## 3. Setup Environment

Copy .env.example menjadi .env.

Generate application key:
php artisan key:generate


## 3. Setup DB DI .ENV

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=inventory_management
DB_USERNAME=root
DB_PASSWORD=

## 4. RUN MIGRATION AND SEEDER
php artisan migrate --seed


## 5. Install npm 
npm install 

## 6. jalankan vite 
npm run dev
